# DESIGN.md — Creative & Ethical Design for AV Metaphors

## Core Framing
This project does **not** aim to “accurately simulate” a diagnosis. It uses **metaphors** based on recurring **experience dimensions** (e.g., intrusion, tension, derealization, rumination pressure).

**Design intent:** Support empathy and understanding without shock or sensationalism.

---

## Design Principles
1. **Dignity & respect:** No caricature, no “edgy” exaggeration for entertainment.
2. **Dimensions over labels:** Prefer experiential dimensions as the creative basis.
3. **Control & reversibility:** Intensity, Safe Mode, Reduced Motion, and Stop Everything must be easy.
4. **Readable UI:** UI stays calm; the artwork lives in the overlay.
5. **Context & consent:** Each condition includes a short explanation and warnings.

---

## Example “Experience → Signal” Mappings (Metaphorical)
These are metaphors, not medical claims.

### Tension / Hyperarousal
- Video: fine grain, vignette (narrowed focus), mild chroma shift
- Audio: gentle noise bed, tremolo/flutter (subtle)

### Dissociation / Derealization
- Video: soft temporal smear (limited), chroma drift, light ghosting
- Audio: lowpass filtering, wow/flutter-like modulation

### Intrusive Thought Pressure
- Video: irregular noise spikes (clamped), interference layer without strobe
- Audio: very light ringmod/granular textures (optional and conservative)

---

## Safety by Design

### Safe Mode (Clamps)
- Caps maximum intensity (e.g., 0.7)
- Restricts feedback and time-based effects
- Avoids high-frequency flicker and harsh contrast spikes
- Prioritizes softer transitions

### Reduced Motion
- Removes/blocks time-based feedback nodes
- Replaces with static or low-motion alternatives when possible

### Warnings
Each condition should include:
- “May feel uncomfortable for some users.”
- Motion sensitivity note (recommend Reduced Motion)
- Audio is optional

---

## UI Tone & Language
- Neutral and supportive; avoid dramatic language
- Avoid “You are…” phrasing
- Use plain explanations: “This is a metaphorical overlay”
- Always provide a clear exit path

---

## Visual Identity Guidelines
- Keep the UI minimal and calm
- Use color sparingly; avoid “alarm red” defaults
- Let the overlay be the primary aesthetic element
