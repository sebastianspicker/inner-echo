# Inner Echo 0.1.0-alpha.1

Release notes for tag `v0.1.0-alpha.1`, following [the alpha release procedure](../RELEASING.md).
They describe only what has been recorded. The CI section is completed from the push-triggered
`main` run of the tagged commit before the GitHub release is published.

## Current capabilities

- A welcome step that explains what the tool is and is not before anything is requested.
- Setup by curated collection (8 catalog entries, including a clean baseline) or by experience
  dimensions (13), with intensity, Safe Mode, Reduced Motion, coupling, and interaction controls.
- A live camera overlay rendered with WebGL, with truthful 2D, raw-preview, and unavailable
  fallbacks.
- An optional Web Audio sound bed, an optional microphone input, and bounded audiovisual coupling.
- Stop Everything, which releases the camera, microphone, audio, render loops, and GPU resources.
- Saved setups (up to 30, kept in the browser) and `#preset=` share links. Opening a link never
  starts media or sound.
- An evidence drawer with the sources, confidence labels, and stated limits behind each experience
  and motif.
- A device-free demo at `/demo/` with mock data and no camera, microphone, audio, storage, or
  network capability.

## Safety and privacy boundaries

- Camera, sound, and microphone each start only from their own direct user action. Startup, saved
  setups, share links, and migrations never start them.
- Everything runs in the browser. There is no backend, account, upload, recording, export,
  analytics, or offline cache.
- Production builds log one console line per camera, microphone, sound, or renderer failure or
  fallback, naming only the state and the error type. They log no device identifiers, media,
  stream details, or preset contents.
- The evidence mappings are metaphor design inputs, not diagnostic or clinical claims.

## Known limitations

- Profile, preset, and interface contracts may change before a stable release.
- No manual evidence has been recorded for this alpha: real Safari, a physical mobile camera,
  keyboard-only navigation, VoiceOver or NVDA, WebGL-disabled behavior, and the headers the live
  host sends. Treat these paths as untested.
- WebGL performance varies by device and browser; fallback modes omit the full effect stack.
- Bare GitHub Pages cannot send the complete header policy, and project sites share an origin with
  other sites under the same account.
- Saved setups exist only in the browser that created them. Saving past 30 removes the oldest, and
  the library notice names it.

## Compatibility and migration

There is no earlier release to upgrade from. This alpha reads the current saved-setup and share-link
format and migrates the legacy single-preset key, but later alphas may change these contracts.
Copy any saved setup you want to keep as a share link before testing a later alpha.
